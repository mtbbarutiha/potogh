# ربات چت ناشناس (مشابه پاتوق) — مرحله ۱

اسکلت ربات تلگرام فارسی با منوی اصلی، ثبت کاربر و پشتیبانی اولیه از لینک دعوت.

## پیش‌نیاز

- Node.js 20+
- توکن ربات از [@BotFather](https://t.me/BotFather)

## راه‌اندازی

```bash
cd patogh-bot
cp .env.example .env
# BOT_TOKEN را در .env قرار بده
npm install
npx prisma migrate dev --name init
npm run dev
```

## منوی فعلی

| دکمه | وضعیت |
|------|--------|
| به یه ناشناس وصلم کن | پیام به‌زودی |
| افراد نزدیک | به‌زودی |
| جستجو کاربران | به‌زودی |
| راهنما | فعال |
| پروفایل | فعال (نمایش اطلاعات) |
| سکه | نمایش موجودی |
| معرفی به دوستان | لینک دعوت فعال |
| لینک ناشناس من | به‌زودی |

## لینک دعوت

`https://t.me/<BOT_USERNAME>?start=ref_<CODE>`

اگر کاربر جدید با این لینک `/start` بزند، `referredById` ثبت می‌شود (بدون پاداش سکه در این مرحله).
